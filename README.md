# Voltory

Voltory — приложение для Android, в котором можно следить за работой солнечного инвертора и домашней энергосистемы. Войдите с учётной записью SmartESS или WatchPower и выберите свой инвертор.

## Возможности

- На главном экране видны мощность солнечных панелей, нагрузка, заряд аккумулятора и потоки энергии между панелями, аккумулятором, домом и сетью.
- Графики и история показаний помогают понять, как менялись выработка и потребление.
- Журнал фиксирует обнаруженные отключения сети. Уведомления о событиях можно включить в настройках.

## Установка и обновления

APK для Android будут публиковаться в разделе [Releases](https://github.com/StiffFox/voltory/releases). Здесь же можно посмотреть, что изменилось в каждой версии.
